# 健身记录 App 开发方案

## 1. 已采用的首版方案

| 项目 | 方案 | 原因 |
| --- | --- | --- |
| 客户端 | ArkTS + ArkUI 原生应用 | HarmonyOS 6.0+ 的官方主路径，原生系统能力完整 |
| 系统基线 | compatibleSdkVersion 20，targetSdkVersion 24 | 覆盖 HarmonyOS 6.0，并使用当前 SDK 编译检查 |
| 架构 | 页面 / 仓储 / 模型 / 服务分层 | 数据模型与 UI 解耦，保留 Android/iOS 迁移接口 |
| 数据 | Preferences 本地 JSON，仓储接口封装 | 首版本机优先，后续可替换数据库或云同步 |
| 媒体 | 系统 Photo Picker，仅保存相册引用 | 不申请全量图库权限，删除记录不删除相册文件 |
| 表格 | UTF-8 CSV | Excel/WPS 可直接打开，无第三方压缩依赖 |
| PDF | HarmonyOS PDFKit | 支持封面、范围筛选、训练摘要和训练图片 |
| 视觉 | 明亮冰蓝渐变 + 半透明磨砂卡片 | 对应已确认的品牌方向和参考截图 |

## 2. 首版用户流程

1. 首页选择日期。
2. 填写体重、感受与一个或多个训练动作；每组分别记录次数和重量，并可填写 RPE/RIR 等训练指标。
3. 可引用图片或视频；保存后日期出现红点，月度热力图同步更新。
4. 在“健身指导”查阅动作要点并跳转权威教程。
5. 在“个人”页维护本地档案、切换分享隐私，或按日期范围导出 CSV/PDF；导出位置由系统文件选择器决定。

## 3. 迭代计划

### M1：本地可用版（当前）

- 训练记录闭环、逐组数据、日历、热力图、媒体选择、动作库、导出。
- 本地数据与最小隐私权限。
- 命令行构建和基础单元测试。

### M2：数据质量与体验

- 动作模板、自定义动作、历史记录复制、训练容量统计。
- 体重趋势、动作 PR、筛选与搜索。
- 媒体查看器、视频播放、压缩与孤立文件清理。
- 训练容量/PR 趋势图与真正 `.xlsx` 输出。

### M3：可选云能力

- 配置 AppGallery Connect 后实现华为账号、云同步、云备份、应用锁和加密导出。
- 使用同一领域模型适配 Android/iOS 客户端或跨端层。

## 4. 当前验收口径

- API 20 兼容配置存在，API 24 SDK 下可编译为 HAP。
- 完成新增、编辑、删除训练记录的本地闭环。
- 日历红点、月次数、热力图随记录变化。
- 系统相册可选图片/视频，附件 URI 与训练记录一起保存。
- CSV/PDF 导出触发系统保存位置选择并写入文件。
- 三个底部导航页面可访问，视觉使用统一磨砂卡片。
